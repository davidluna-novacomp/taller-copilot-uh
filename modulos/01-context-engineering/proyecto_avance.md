# Proyecto en avance — Módulo 1: AI Development Context de TaskFlow

## Qué se construye en este módulo

El **contexto de desarrollo con IA** inicial del proyecto final, tal como se definió en `practica.md`.

## Tareas a entregar

1. Crear en tu repositorio del proyecto final un archivo `ai-context.md` (o similar) con las secciones:
   - Arquitectura
   - Convenciones
   - Restricciones
   - Definition of Done
   - Estándares de testing
2. El contenido debe reflejar **tu stack real** (no necesariamente el de ejemplo en `practica.md`).
3. Ejecutar el experimento de comparación (con/sin contexto) descrito en `practica.md`, usando una funcionalidad simple de TaskFlow (por ejemplo, "crear una tarea").
4. Documentar en 3-5 líneas qué cambió en la respuesta de Copilot al usar el contexto.
5. Identificar al menos un candidato a Skill (conocimiento especializado, no aplicable a todo el proyecto o demasiado extenso para una instrucción global) y anotarlo para formalizarlo en el Módulo 2.

## Checklist de aceptación

- [ ] El archivo de contexto existe y está versionado (commit en el repositorio del proyecto final).
- [ ] Cada sección tiene contenido específico del proyecto (no genérico ni copiado literalmente del ejemplo).
- [ ] Existe evidencia (capturas o texto) de la comparación con/sin contexto.
- [ ] El contenido es revisado en pareja o con el instructor: ¿es mínimo, relevante y mantenible?
- [ ] Existe al menos un candidato a Skill identificado y justificado (o se documenta explícitamente que no aplica todavía).

## Conexión con el siguiente módulo

En el Módulo 2 este contenido se formalizará como `.github/copilot-instructions.md` y, si aplica, instrucciones específicas por ruta y Skills — no se descarta, se reorganiza y se hace persistente de forma estándar.
