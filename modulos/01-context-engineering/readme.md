# Módulo 1. Copilot avanzado y Context Engineering (2 h)

## Objetivo del módulo

Evolucionar del prompt aislado hacia la construcción deliberada de **contexto técnico** que permita obtener de GitHub Copilot respuestas más consistentes, relevantes y alineadas con la arquitectura del proyecto.

**Resultado principal:** construir contexto útil y persistente para el equipo.

## Estrategia de la sesión

Se sigue la metodología general del curso (sección 6 de la propuesta), aplicada a este módulo:

| Componente | Aplicación en este módulo |
| :---- | :---- |
| **Concepto breve** | Diferencia entre Prompt Engineering y Context Engineering; qué contexto usa Copilot y de dónde lo toma (incluyendo instrucciones always-on y Skills activados bajo demanda). |
| **Demostración guiada** | El instructor muestra cómo una misma petición da resultados distintos con y sin contexto persistente. |
| **Laboratorio** | Cada estudiante diseña el "AI Development Context" de su proyecto final (ver `proyecto_avance.md`). |
| **Discusión técnica** | Qué información vale la pena persistir vs. qué genera sobrecarga/ruido, y cuándo conviene empaquetar conocimiento especializado como un Skill en lugar de una instrucción global. |
| **Validación** | Revisar que el contexto creado sea mínimo, relevante y mantenible. |
