# Recursos — Módulo 1: Copilot avanzado y Context Engineering

> Nota: verifica la vigencia de los enlaces antes de cada cohorte, ya que la documentación de GitHub Copilot se actualiza con frecuencia.

## Documentación oficial

- GitHub Copilot — Custom instructions and prompt files: https://docs.github.com/en/copilot/concepts/prompting/response-customization
- GitHub Copilot — Documentación general (buscar la sección de Skills/Agent Skills, es una capacidad reciente y en evolución): https://docs.github.com/en/copilot

## Conceptos relacionados para profundizar

- Ingeniería de contexto (Context Engineering) como evolución del Prompt Engineering: buscar publicaciones recientes de GitHub/Microsoft sobre el tema en el blog oficial de GitHub (https://github.blog).
- Principios de "menos pero mejor" en documentación técnica: cualquier referencia de tu organización sobre guías de estilo y Architecture Decision Records (ADR), ya que son un buen insumo de contexto de arquitectura.

## Sugerencia para el instructor

Complementar con ejemplos reales (anonimizados) de `copilot-instructions.md` de repositorios públicos del cliente o de proyectos open source conocidos por el grupo, para discutir qué reglas son verificables y cuáles no.
