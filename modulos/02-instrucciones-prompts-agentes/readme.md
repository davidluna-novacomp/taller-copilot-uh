# Módulo 2. Instrucciones, prompts reutilizables y agentes (2 h)

## Objetivo del módulo

Estandarizar la interacción del equipo con Copilot mediante **artefactos versionados y reutilizables** que reduzcan la variabilidad y hagan explícitas las reglas de ingeniería del proyecto — instrucciones always-on, Skills activados bajo demanda y prompt files invocados explícitamente.

**Resultado principal:** estandarizar comportamiento y tareas recurrentes.

## Estrategia de la sesión

| Componente | Aplicación en este módulo |
| :---- | :---- |
| **Concepto breve** | Mapa completo de `.github/` relacionado con contexto: instrucciones (globales y por ruta), `AGENTS.md` (incluyendo anidación), chat modes, prompt files, Skills y plantillas de issues/PR. |
| **Demostración guiada** | El instructor muestra cómo `.github/copilot-instructions.md` cambia el comportamiento por defecto de Copilot en un repositorio real. |
| **Laboratorio** | Cada estudiante formaliza el contexto del Módulo 1 en instrucciones versionadas y crea prompt files reutilizables. |
| **Discusión técnica** | Cómo evitar conflictos entre instrucciones globales, por ruta, `AGENTS.md` y chat modes. |
| **Validación** | Revisar que las instrucciones sean concisas, verificables y sin contradicciones. |
