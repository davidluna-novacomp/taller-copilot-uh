# Recursos — Módulo 2: Instrucciones, prompts reutilizables y agentes

> Verifica la vigencia de los enlaces antes de cada cohorte.

## Documentación oficial

- GitHub Copilot — Custom instructions and prompt files: https://docs.github.com/en/copilot/concepts/prompting/response-customization
- GitHub Copilot — Documentación general (buscar también chat modes y `copilot-setup-steps.yml` para el coding agent): https://docs.github.com/en/copilot
- `AGENTS.md` — estándar abierto adoptado por varias herramientas de IA para instrucciones orientadas a agentes: https://agents.md

## Para profundizar

- Buscar en el repositorio de tu organización ejemplos existentes de `.github/copilot-instructions.md` en otros proyectos, como referencia de qué reglas han funcionado.
- Revisar convenciones de estilo/lint ya definidas en el proyecto (ESLint, Checkstyle, StyleCop, etc.) como insumo directo para las instrucciones — evita reinventar reglas que ya existen en una herramienta automatizada.
- Revisar las plantillas `.github/ISSUE_TEMPLATE/*.md` y `.github/PULL_REQUEST_TEMPLATE.md` ya existentes en tus proyectos reales: son contexto que el equipo ya mantiene, aunque no se haya pensado originalmente para IA.

## Sugerencia para el instructor

Llevar 2-3 ejemplos reales de prompt files (genéricos, sin datos sensibles) para mostrar variaciones de patrones: análisis, generación de tests, documentación y revisión.
