# Proyecto en avance — Módulo 3: Especificación de TaskFlow

## Qué se construye en este módulo

Los artefactos de Spec-Driven Development para la primera funcionalidad real de TaskFlow: **crear y listar tareas**.

## Tareas a entregar

1. Redactar la `constitution.md` de tu proyecto final.
2. Redactar la especificación (`specify`) de "crear y listar tareas": historias de usuario + criterios de aceptación.
3. Documentar el proceso de clarificación: al menos 3 preguntas y sus respuestas.
4. Redactar el plan técnico correspondiente.
5. Descomponer el plan en tareas ejecutables y verificar consistencia (`analyze`) entre especificación, plan y tareas.

**Importante:** en este módulo **no se implementa código todavía** — la implementación ocurre en el Módulo 4, integrada con agentic development.

## Checklist de aceptación

- [ ] Existe `constitution.md` versionado en el repositorio del proyecto final.
- [ ] La especificación no contiene decisiones de implementación (están solo en el plan).
- [ ] El proceso de clarificación quedó documentado.
- [ ] Cada criterio de aceptación tiene al menos una tarea asociada (verificado manualmente o con `analyze`).

## Conexión con el siguiente módulo

En el Módulo 4, estas tareas se implementarán delegando trabajo a un agente de Copilot, aplicando el patrón Plan → Execute → Verify y, si el entorno lo permite, conectando una herramienta externa vía MCP.
