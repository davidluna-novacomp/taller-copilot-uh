# Módulo 4. Agentic Development y Model Context Protocol (MCP) (3 h)

## Objetivo del módulo

Comprender cuándo delegar trabajo a agentes de Copilot y cómo extender sus capacidades con herramientas externas **sin perder control, trazabilidad ni seguridad**.

**Resultado principal:** delegar tareas y conectar herramientas de forma controlada.

## Estrategia de la sesión

| Componente | Aplicación en este módulo |
| :---- | :---- |
| **Concepto breve** | Diferencia entre pedir una respuesta y delegar una tarea multi-step; patrón Plan → Execute → Verify; qué es MCP. |
| **Demostración guiada** | El instructor delega al agente la implementación de las tareas del Módulo 3 y muestra el uso de una herramienta MCP. |
| **Laboratorio** | Cada estudiante implementa su funcionalidad especificada usando agent mode, con supervisión activa. |
| **Discusión técnica** | Permisos, allowlists, mínimo privilegio y cuándo NO usar un agente. |
| **Validación** | Verificar que el resultado del agente cumple las tareas y no excedió el alcance definido. |
