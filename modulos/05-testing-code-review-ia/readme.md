# Módulo 5. Testing y Code Review asistidos por IA (2 h)

## Objetivo del módulo

Utilizar IA como mecanismo de **ampliación del criterio de calidad**, evitando confundir mayor volumen de tests o sugerencias con software correctamente validado.

**Resultado principal:** elevar calidad y capacidad de verificación.

## Estrategia de la sesión

| Componente | Aplicación en este módulo |
| :---- | :---- |
| **Concepto breve** | De criterios de aceptación a casos de prueba; checklist de revisión de PR. |
| **Demostración guiada** | El instructor genera tests y realiza code review asistido sobre un PR con fallas deliberadas. |
| **Laboratorio** | Cada estudiante amplía la cobertura de pruebas de su funcionalidad y revisa un PR con el checklist. |
| **Discusión técnica** | Revisión automatizada vs. revisión humana: qué detecta cada una y qué se le escapa. |
| **Validación** | Comparar hallazgos de Copilot, herramientas automáticas y revisión humana sobre el mismo PR. |
