# Recursos — Módulo 5: Testing y Code Review asistidos por IA

> Verifica la vigencia de los enlaces antes de cada cohorte.

## Documentación oficial

- GitHub Copilot — Documentación general (incluye guías de uso en pull requests y revisión de código): https://docs.github.com/en/copilot

## Para profundizar

- Buenas prácticas de testing del framework específico del stack del grupo (ej. Jest, JUnit, pytest, xUnit) — revisar la documentación oficial de esa herramienta.
- Prácticas de Behavior-Driven Development (BDD) para redactar casos de prueba directamente desde criterios de aceptación.
- Guías internas de code review del cliente, si existen, para adaptar el checklist de `teoria.md` a sus estándares reales.

## Sugerencia para el instructor

Preparar con anticipación el PR con fallas deliberadas (Parte B de `practica.md`) en el stack real del grupo, evitando que las fallas sean tan obvias que no requieran análisis, ni tan sutiles que resulten injustas para una sesión de 2 horas.
