# Proyecto en avance — Módulo 6: Seguridad y gobernanza de TaskFlow

## Qué se construye en este módulo

Un checklist de seguridad/gobernanza aplicado a la funcionalidad existente, e incorporado a la Definition of Done del proyecto.

## Tareas a entregar

1. Completar el checklist de `practica.md` sobre la implementación actual de "crear y listar tareas".
2. Corregir al menos un hallazgo real encontrado (o documentar explícitamente por qué no aplica/no se encontró ninguno).
3. Actualizar `.github/copilot-instructions.md` (o el archivo de Definition of Done del proyecto) para incluir este checklist como parte de los criterios de aceptación futuros.
4. Documentar, para el cambio de este módulo, quién/qué generó, qué validó y quién aprobó (separación Generate ≠ Validate ≠ Approve).

## Checklist de aceptación

- [ ] El checklist de seguridad/gobernanza fue aplicado y documentado.
- [ ] Al menos un hallazgo fue corregido (o justificado si no hay hallazgos).
- [ ] La Definition o Done del proyecto quedó actualizada para incluir este checklist hacia adelante.
- [ ] Existe evidencia de la separación Generate / Validate / Approve para este incremento.

## Conexión con el siguiente módulo

En el Módulo 7 se agregará observabilidad (logging, métricas, trazas) a esta misma funcionalidad y se definirán KPIs, cerrando el conjunto de controles de calidad antes del laboratorio integrador del Módulo 8.
