# Módulo 6. Seguridad, gobernanza y uso responsable (2 h)

## Objetivo del módulo

Definir controles mínimos para que el uso de Copilot y de capacidades agénticas sea compatible con los requisitos de **seguridad, privacidad y gobierno** de la organización.

**Resultado principal:** establecer controles para desarrollo asistido por IA.

## Estrategia de la sesión

| Componente | Aplicación en este módulo |
| :---- | :---- |
| **Concepto breve** | Código generado por IA como código no confiable hasta ser verificado; separación Generate ≠ Validate ≠ Approve. |
| **Demostración guiada** | El instructor muestra riesgos típicos (secretos expuestos, dependencias inexistentes, validación insuficiente) en código generado por IA. |
| **Laboratorio** | Cada estudiante aplica un checklist de seguridad/gobernanza a su funcionalidad del proyecto final. |
| **Discusión técnica** | Permisos de agentes/MCP y minimización de alcance en la práctica del equipo. |
| **Validación** | Verificar que el checklist quedó incorporado a la Definition of Done del proyecto. |
