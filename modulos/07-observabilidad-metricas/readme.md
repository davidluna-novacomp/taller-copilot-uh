# Módulo 7. Observabilidad y métricas (2 h)

## Objetivo del módulo

Evaluar tanto la **adopción de Copilot** como su efecto sobre el delivery, evitando medir éxito únicamente por actividad o cantidad de código generado.

**Resultado principal:** medir adopción e impacto sobre el delivery.

## Estrategia de la sesión

| Componente | Aplicación en este módulo |
| :---- | :---- |
| **Concepto breve** | Observabilidad del uso de Copilot vs. observabilidad del software producido; métricas de adopción vs. impacto. |
| **Demostración guiada** | El instructor muestra dimensiones de análisis disponibles y cómo correlacionarlas con métricas de ingeniería. |
| **Laboratorio** | Cada estudiante define KPIs propios y agrega observabilidad mínima a su funcionalidad del proyecto final. |
| **Discusión técnica** | Riesgos de medir solo actividad/volumen sin relacionarlo con calidad o impacto real. |
| **Validación** | Revisar que el cuadro de mando propuesto separe adopción, productividad, calidad y riesgo. |
