# Módulo 8. Laboratorio integrador end-to-end (4 h)

## Objetivo del módulo

Consolidar los aprendizajes ejecutando un **flujo completo** sobre una funcionalidad realista, desde el requisito hasta el Pull Request y la evaluación de métricas y controles.

**Resultado principal:** aplicar el flujo completo en una funcionalidad realista.

## Estrategia de la sesión

| Componente | Aplicación en este módulo |
| :---- | :---- |
| **Concepto breve** | Repaso rápido del flujo integrador de 10 pasos (sección 9 de la propuesta). |
| **Demostración guiada** | El instructor recorre el flujo completo sobre un ejemplo distinto al de "crear y listar tareas". |
| **Laboratorio** | Cada estudiante/equipo entrega una funcionalidad nueva de TaskFlow aplicando todo el flujo. |
| **Discusión técnica** | Retrospectiva: qué delegó la IA, qué verificó el equipo, qué evidencia quedó disponible. |
| **Validación** | Evaluación práctica final (ver sección 11 de la propuesta: 50% del peso total). |

## El flujo integrador (10 pasos)

1. Requirement → 2. Spec Kit → 3. Context & Instructions → 4. Agent → 5. Testing → 6. Security → 7. Observability → 8. Pull Request → 9. Code Review → 10. Metrics & Retrospective.
